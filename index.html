BEAR.Resource JSON Schemas

JSON Schema definitions for BEAR.Resource Semantic Logging - structured performance profiling data designed for AI understanding.

  • Semantic Log

    Main schema for semantic log structure

    schemas/semantic-log.json

  • Open Context

    Schema for resource request initiation context

    schemas/open-context.json

  • Complete Context

    Schema for successful resource completion context

    schemas/complete-context.json

  • Error Context

    Schema for resource error context

    schemas/error-context.json

  • Profile Data

    Schema for profiling data (XHProf, Xdebug, PHP backtrace)

    schemas/profile.json

  • OPTIONS Response

    Schema for BEAR.Resource OPTIONS method response - provides machine-readable API documentation for available resource methods

    Example from docs/options/doc.json:
    Defines GET method with required "id" parameter (string), POST method with "id" (required), "name" and "age" (optional with defaults), and empty DELETE array indicating method not supported.

    Use cases: Self-documenting APIs, automatic client generation, parameter validation, API discovery

    schemas/options-response.json
