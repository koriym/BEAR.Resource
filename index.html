OPTIONS Response

Schema for BEAR.Resource OPTIONS method response - provides machine-readable API documentation for available resource methods

Example: Defines GET method with required "id" parameter, POST method with optional defaults, and empty DELETE array for unsupported methods.

Use cases: Self-documenting APIs, automatic client generation, parameter validation, API discovery

schemas/options-response.json

ALPS Profile

Application-Level Profile Semantics for BEAR.Resource semantic profiling operations

ALPS (RFC Draft): Defines semantic descriptors for Resource-Oriented Architecture profiling, including development vs production patterns, multi-dimensional profiling data (XHProf, Xdebug, PHP), and resource operation semantics.

Machine-readable semantics: Enables AI to understand profiling context, operation types, and performance data meaning without human explanation.

schemas/bear-resource-alps.json
